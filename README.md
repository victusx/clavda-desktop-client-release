# Clavda Desktop

Installers for Clavda Desktop.

Download the newest build from [Releases](https://github.com/victusx/clavda-desktop-client-release/releases/latest).

## Install

| System | File |
| --- | --- |
| Windows | `Clavda Desktop_<version>_x64-setup.exe` |
| Linux | `.AppImage`, `.deb`, or `.rpm` |

## Setup

1. Install and open Clavda Desktop.
2. In the Clavda dashboard, open the device and choose **Download Config (.env)**.
3. Drop that file on the window, or choose it on the Device tab.
4. Press **Connect**.

## Updates

A new version shows in the sidebar with **Install**. **Setup** has **Check for updates**.
